# Презентации курса

- На титульных слайдах указывай тему, при необходимости — подзаголовок. Не добавляй дату и номер семинара.
- Для каждой темы C храни материалы в `c-course/<тема>/`: исходники Marp в `slides/`, заметки в `notes/`, задания и код в `livecoding/`, PDF непосредственно в папке темы.
- В `dev` храни все материалы семинара. В `main` переносится только PDF со слайдами. Создавай коммиты только после явного разрешения пользователя.
