# Указатели и массивы: практика

Поиск, транспонирование и умножение матриц

---

# Задача 1: минимум и максимум

```c
int minmax(const int *a, size_t n,
           int *lo, int *hi);
```

- За *один проход* найти минимум и максимум. Записать их в два разных объекта по адресам `lo` и `hi`, вернуть `1`.
- Если `n == 0`, вернуть `0`, ничего не читать и не менять.

# Задача 2: транспонировать прямоугольник

```c
void transpose(size_t rows, size_t cols,
               int src[rows][cols], int dst[cols][rows]);
```

- Размеры положительны. `src` и `dst` — два разных неперекрывающихся массива. `src` не меняем.
- Каждый `src[i][j]` переносим в `dst[j][i]`.

```text
    1  2  3           1  4
    4  5  6     →     2  5
                      3  6
```

Почему у результата *три строки по два элемента*?

# Задача 3: квадрат на месте

```c
void transpose_square(size_t n, int a[n][n]);
```

- `n > 0`. Транспонировать тот же массив, используя одну временную переменную для обмена.
- Диагональ не меняется. Как выбрать пары, чтобы не поменять каждую дважды?

```text
    1  2  3           1  4  7
    4  5  6     →     2  5  8
    7  8  9           3  6  9
```

# Задача 4: перемножить матрицы

```c
void matmul(size_t m, size_t k, size_t n,
            int a[m][k], int b[k][n], long long c[m][n]);
```

- `A` имеет размер `m × k`, `B` — `k × n`, результат — `m × n`.
- `C[i][j]` — скалярное произведение строки `i` матрицы `A` и столбца `j` матрицы `B`.
- Размеры положительны. `C` не перекрывается с `A` или `B`. Произведения и промежуточные суммы помещаются в `long long`. Приведите операнд к этому типу *до* умножения.

---

# Эксперимент: транспонировать `B`

| При фиксированных `i`, `j` | Чтение в цикле по `t` |
| --- | --- |
| `a[i][t] * b[t][j]` | Строка `A` подряд, столбец `B` с шагом строки |
| `a[i][t] * bt[j][t]` | Обе строки подряд, где `bt = Bᵀ` |

- Сравните `i–j–t` и тот же порядок с `Bᵀ` на нескольких размерах. У обеих версий сложность `O(m * k * n)`.
- Замерьте *транспонирование*, *умножение после него* и *суммарное время*. Что изменится, если `Bᵀ` используется многократно?

# Первая позиция для вставки

```c
size_t lower_bound(const int *a, size_t n, int key);
```

- Массив отсортирован по неубыванию. Найдите первый индекс с `a[i] >= key`; если такого нет, верните `n`.
- Дубликаты разрешены. Цель — `O(log n)` времени и `O(1)` дополнительной памяти.
- Ищем границу между элементами `< key` и `>= key`. Что вернуть, если массив пуст?

# Элемент большинства

```c
int majority(const int *a, size_t n, int *out);
```

- Найдите число, которое встречается *строго больше* `n / 2` раз. Верните `1` и запишите его в `*out`. Если его нет, верните `0`, не меняя `*out`.
- Массив менять нельзя. Цель — `O(n)` времени и `O(1)` дополнительной памяти.
- Ровно половины недостаточно. Как отличить кандидата от настоящего большинства?

# Быстрое возведение матрицы в степень

- Дана квадратная матрица `A` и целая степень `e ≥ 0`. Найдите `Aᵉ` по модулю `1009`. Для `e = 0` результат — единичная матрица.
- Можно переиспользовать умножение матриц. Для примера возьмите `1 ≤ n ≤ 32`, элементы от `0` до `1008`, степень до `10⁹`.
- Цель — *`O(log e)` умножений* при `e ≥ 2`. Как после возведения в квадрат уменьшить показатель вдвое? Куда писать результат промежуточного умножения?
